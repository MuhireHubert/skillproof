## Main Version 4 workspace

The Network screen is deliberately institutional. It uses tables, status pills, competency meters and short operational explanations instead of conversational AI patterns.

The screen should evolve from sample values to database-backed aggregates as the network grows.

## Visual direction

Use a restrained university/institutional visual system:
- dark ink header
- white surfaces
- muted borders
- green verification/accomplishment states
- amber review states
- blue information states
- compact typography
- tables and structured forms
- no AI branding
- no chat-first interaction
- no decorative futuristic gradients

The platform should feel like serious professional infrastructure used by registrars, deans, career offices, HR teams and industry bodies.
